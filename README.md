
# Netflix Power BI Dashboard
Netflix Content Analysis Dashboard Created using Microsoft Power BI  
Project Overview

An interactive Power BI dashboard for analyzing Netflix movies and TV shows.

Dashboard Analysis

- Total titles
- Movies vs TV Shows
- Content by country
- Content by release year
- Ratings analysis
- Genre analysis
- Director analysis
- Content distribution and trends

Key Insights

- Analysis of Netflix's content library
- Comparison between Movies and TV Shows
- Identification of popular genres and ratings
- Analysis of content growth over the years
- Geographical distribution of Netflix content

Tools Used

- Microsoft Power BI
- Data Analysis
- Data Visualization
- DAX
